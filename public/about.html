Free social media scheduler

Toasty Posty is a free, open-source app for writing a post once and sending it to X, Bluesky, Reddit, Instagram and TikTok, now or on a schedule. There's no sign-up: your accounts and API keys stay in your own browser.

Open Toasty PostySource on GitHub

What it does

Write once, preview everywhere

See exactly how a post will look on each network, with live character counts. Write a different version for any platform.

Schedule with a dial

Pick a time on the browning dial and pull the lever. Drafts, a weekly view and failed-post retries live in the Queue.

AI that sounds like you

Optional Claude or OpenAI key: draft captions for each platform, rewrite, write alt text and generate images, in your own house voice.

Feeds for ideas

Track topics across Google News, Hacker News and Reddit, or follow RSS, Medium, Substack, YouTube and more for free. Hit “Toast” to post about anything.

Your keys, your browser

No database, no accounts. A stateless relay forwards each request to the network and keeps nothing. Back up or restore anytime.

Open source

MIT licensed. Run it on your own computer with Node.js or deploy your own copy to Vercel.

How your data is handled

  • Stored in your browser. Accounts, keys, posts, feeds and media are saved in this browser's storage on your device. Another browser or device starts empty unless you restore a backup.
  • Relayed, never kept. Networks don't accept posts straight from a web page, so each request passes through Toasty Posty's server, which forwards it and forgets it.
  • No tracking. No analytics, no ads, no account.
  • Scheduling needs an open tab. Scheduled posts go out while Toasty Posty is open somewhere (a background tab is fine). Missed ones go out the next time you open it.

Questions

Is Toasty Posty free?

Yes, free and open source under the MIT license. You use your own developer keys for each network, and optional AI features use your own Claude or OpenAI key.

Which social networks does it support?

X (Twitter), Bluesky, Reddit, Instagram (professional accounts) and TikTok. Each network's rules apply; for example, TikTok keeps posts private until it audits your developer app.

Where are my API keys stored?

In your own browser. Toasty Posty has no database or accounts. Keys pass through the stateless relay only when a request needs them, and aren't saved there.

How does scheduling work?

Scheduled posts go out from any open Toasty Posty tab, even in the background. Anything that came due while it was closed goes out the next time you open it.

Can it write captions with AI?

Yes. With a Claude or OpenAI key it drafts a version per platform, rewrites posts and writes alt text. Image generation uses OpenAI. Without a key, those tools stay locked.

Can I host my own copy?

Yes. Run npm install then npm start on your computer, or deploy to Vercel. You can set an ACCESS_CODE so only you can use your deployment.
